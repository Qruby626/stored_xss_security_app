STORED XSS SECURITY LAB

Lingkungan Simulasi Pengujian Keamanan Web

Laboratorium simulasi yang menyediakan lingkungan pengujian terhadap serangan Stored Cross-Site Scripting (XSS) menggunakan fitur aplikasi akademik sebagai media pengujian payload dan mekanisme keamanan berbasis CSP Nonce Dinamis dan Rule-Based Detection.

Cara Kerja Sistem

Dua Modul Utama

Payload Stored XSS diuji melalui Modul Simulasi Akademik, kemudian dideteksi, dibatasi, dan dievaluasi oleh Security Engine.

Target Pengujian

Modul Simulasi Akademik

Berfungsi sebagai lingkungan simulasi tempat payload Stored XSS diinjeksikan melalui fitur input dinamis, disimpan, dan ditampilkan kembali sebagai media pengujian mekanisme keamanan.

Mekanisme Keamanan

Security Engine

Menangani mekanisme keamanan yang merespons aktivitas pengujian dari Modul Simulasi melalui Rule-Based Detection berbasis regex, penerapan CSP Nonce Dinamis, penerimaan CSP Reports, pencatatan log deteksi, dan evaluasi metrik pengujian.

  • Rule-Based Detection
  • CSP Nonce Dinamis
  • CSP Reports
  • Log Deteksi
  • Evaluasi Pengujian

Aplikasi ini hanya digunakan untuk simulasi penelitian akademik di lingkungan localhost. Seluruh payload digunakan semata-mata untuk kebutuhan pengujian Stored XSS.
