Panduan Pengujian Stored XSS

Panduan pelaksanaan skenario pengujian, langkah pengujian, dan dataset payload Stored XSS yang digunakan dalam penelitian.

Skenario 1

Detection OFF CSP OFF
Tujuan: Menetapkan baseline eksekusi payload Stored XSS tanpa proteksi aplikasi.
Langkah Pengujian:
  1. Gunakan modul Simulasi Akademik.
  2. Nonaktifkan Detection dan CSP di Dashboard Keamanan.
  3. Pilih dan salin payload dari dataset.
  4. Tempel payload ke target pengujian dan kirim.
  5. Refresh halaman dan amati eksekusi.
Hasil yang Diharapkan: Payload tersimpan dan berhasil dieksekusi tanpa deteksi maupun blokir.

Skenario 2

Detection ON CSP OFF
Tujuan: Mengevaluasi kemampuan Rule-Based Detection mendeteksi payload tanpa proteksi browser.
Langkah Pengujian:
  1. Aktifkan Detection dan nonaktifkan CSP.
  2. Gunakan payload yang sama dan salin.
  3. Tempel payload ke target pengujian dan kirim.
  4. Refresh halaman dan amati deteksi.
  5. Verifikasi catatan di Log Deteksi.
Hasil yang Diharapkan: Payload terdeteksi oleh Rule-Based Detection dan tercatat di Log Deteksi.

Skenario 3

Detection OFF CSP ON
Tujuan: Mengukur kemampuan CSP Nonce Dinamis memblokir eksekusi payload tanpa deteksi rule.
Langkah Pengujian:
  1. Nonaktifkan Detection dan aktifkan CSP.
  2. Pilih dan salin payload dari dataset.
  3. Tempel payload ke target pengujian dan kirim.
  4. Refresh halaman dan amati pemblokiran browser.
  5. Periksa laporan CSP jika terjadi pelanggaran.
Hasil yang Diharapkan: Browser memblokir payload melalui CSP dan Laporan CSP tercatat, tanpa deteksi rule.

Skenario 4

Detection ON CSP ON
Tujuan: Menguji integrasi proteksi ganda dan konsistensi pelaporan dalam skenario aplikasi nyata.
Langkah Pengujian:
  1. Aktifkan Detection dan CSP.
  2. Pilih payload yang sama dan salin.
  3. Tempel payload ke target pengujian dan kirim.
  4. Refresh halaman dan amati hasil deteksi serta pemblokiran.
  5. Konfirmasi laporan di Log Deteksi, Laporan CSP, dan Dashboard Keamanan.
Hasil yang Diharapkan: Payload terdeteksi, eksekusi diblokir, dan hasil tercatat dalam laporan serta dashboard.

Target Pengujian

Keempat fitur digunakan sebagai media penyimpanan payload Stored XSS untuk mensimulasikan kondisi aplikasi web nyata.
